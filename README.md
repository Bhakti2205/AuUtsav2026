# 🎉 UTSAV 2026 — Adani University Annual Cultural Fest

A vibrant, feature-rich website for **UTSAV 2026**, the Annual Cultural Extravaganza at **Adani University, Ahmedabad**.

---

## 🌟 Features

- 🎭 **12 Events** across 5 categories: Dance, Singing, Comedy, Dare, Cultural
- ⏳ **Live Countdown** Timer to fest start date
- 📅 **3-Day Schedule** with day-wise timetable
- 📸 **Gallery** with lightbox viewer
- 📝 **Registration Form** with multi-event selection
- 📞 **Contact** organizer info section
- ⚙ **Admin Panel** — manage events, view registrations, export CSV

---

## 🗂 Project Structure

```
adani-fest/
├── index.html        # Main public website
├── admin.html        # Admin panel
├── css/
│   ├── style.css     # Global dark festive theme
│   └── admin.css     # Admin panel styles
├── js/

│   ├── app.js        # Main website logic
│   └── admin.js      # Admin panel logic
└── img/              # (Add event images here)
```
